How to study with these lessons

  1. Find the next task in tasks/todo.md. Look it up in the "Read before each task" table below.
  2. Read the lesson(s) for that task. Do the Practice part. Answer the quiz without opening the answers first.
  3. Build the task (/agent-skills:build). While it runs, keep the lesson open and match each file to an idea from the lesson.
  4. Read the learning note for the task in docs/learn/<module>/task<N>.md. Then tick "I finished this lesson" at the bottom of the lesson.
